# Amazon Sales Dataset Analysis

## Overview
Exploratory Data Analysis (EDA) of the Amazon Sales Dataset using Python to understand sales trends, product categories, customer behaviour, and order fulfilment.

## Objectives
- Analyze sales across product categories.
- Examine monthly sales trends.
- Understand order status and fulfilment.
- Analyze geographical distribution of orders.
- Identify sales outliers.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Analysis
- Data loading and cleaning
- Exploratory data analysis
- Data visualization
- Outlier analysis
- Conclusion
